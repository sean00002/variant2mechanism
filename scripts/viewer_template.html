variant2mechanism · agent run traces

From a non-coding variant to a testable TF mechanism

An agent drafts mechanism chains (TF, allele, element, gene, cell type, phenotype) plus a "no TF effect" chain. A critic grades every link against logged evidence. The agent then plans tool calls against the weakest links, states what each result should show, runs them, revises and is graded again, for up to three rounds. Every claim cites an evidence ID.
