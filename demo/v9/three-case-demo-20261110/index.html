variant2mechanism · small open-source agent demo · 10 November 2026

From a variant to an auditable partial mechanism.

Agents propose claims, inspect experiments and revise hypotheses. Every accepted link keeps its evidence and scope. Missing links stay visible.

Three known-variant examples: one historical development run and two new checks with the implementation frozen beforehand. Only coordinates, alleles and germline/somatic origin were supplied.

Current result: the historical case retains two supported binding claims. Neither new case recovered a supported molecular claim within its resource limits. This is a transparent engineering demo with diagnosed failures, not evidence that mechanism recovery is reliable yet.

1 · Propose

Build candidate mechanism chains from variant annotation, regulatory databases and saved QBiC predictions.

2 · Investigate and repair

Read primary studies, follow citations, verify experiments and repair individual claims without discarding valid evidence.

3 · Report two things

Which molecular claims are supported? Which required links remain unresolved? A partial finding need not be a complete disease explanation.

Finding a paper, accepting an experiment and adopting it into a hypothesis are separate checkpoints. Factor recovery below refers to evidence-linked claims, not a name appearing in generated prose.

Small, general changes to test next

  1. Bound the evidence shown to each model. Preserve every raw record and candidate. Group repeated associations by trait, target, tissue and source; pass a compact index with evidence IDs and allow focused expansion. Check retrieval coverage and token use on the same frozen inputs. Reducing repeated payload is different from rejecting weak candidates.
  2. Resolve paper-local names, then map to the case. Store an explicit source-backed mapping from a paper's shorthand to its stated coordinate and allele. Separately verify assembly conversion and strand orientation using a trusted variant resource. Multiple mutations in one article require separate mappings; ambiguous mappings stay unresolved. Test synthetic aliases, two nearby variants, opposite strands and incomplete build information, not only TERT.
  3. Refine the claim to the assay. Retain a verified reporter result as a reporter-scoped molecular claim while leaving the endogenous mechanism unresolved. Article identity, case identity and assay applicability are three separate checks.
  4. Repair the CIViC adapter and add a recorded-response contract check. Treat API errors separately from an empty result. Then evaluate one fixed revision under a separately agreed budget, including unresolved or negative controls.

What changed in this version
