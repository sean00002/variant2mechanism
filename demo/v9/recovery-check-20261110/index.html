What changed

  1. Compact evidence views. Keep all raw records. Show bounded details plus an index, with a local evidence_inspect tool to retrieve omitted records by ID or text/page. On the same saved evidence set, the evidence section changed from 628,597 to 31,729 characters (95.0% smaller). This is a packet diagnostic, not a live token benchmark.
  2. Discovery diversity. A broad, truncated literature search can mix relevance-ranked and citation-ranked results under the same query. The additional retrieval and its status are recorded. Citation count helps locate papers; it never contributes biological support.
  3. Source-backed variant identity. An explicit article-local mutation definition can identify the tested coordinate. NCBI primary-assembly placements separately verify the exact input substitution and the strand conversion. The paper notation remains in the experiment record. Ambiguous aliases, wrong alleles and unsupported builds remain unresolved.
  4. Claims follow assay scope. Agents are instructed to retain a reporter-scoped claim while leaving endogenous activity and disease mediation open. A reporter does not directly settle an explicitly endogenous activity claim. No factor or target is inserted by code.
  5. CIViC schema repair. Alias objects are requested with their name field and converted to names before matching. Browse and variant-detail queries passed a public-API contract check. API failures stay separate from empty searches.

The next improvement suggested by these traces

Make a failed extraction a repair task against the same source. The rs12740374 run found the correct primary paper, but failed passage verification and then spent four reads on another paper's abstract. More currency did not fix this decision loop.

  1. Retain the failed read ID, passage location and specific validator error in a repair queue. Repair quote selection or scope before launching a new discovery search.
  2. Have the model select source sentence IDs or verified spans; copy the source text in code. This avoids altered punctuation and overlong quotations without weakening provenance checks.
  3. Keep a measured allele difference separate from its unresolved mapping to the case's reference/alternate allele. Do not infer minor equals alternate, or treat uncertainty about direction as evidence that the assay never happened.
  4. Stop repeated abstract-only reads when they return no new information; follow an available full-text section, supplement or citation instead. Show identity metadata separately from biological evidence.

These are recommendations from the final audit, not changes made between the two frozen reruns. No additional agents, TF exceptions or case-specific source lists are needed for this repair.
