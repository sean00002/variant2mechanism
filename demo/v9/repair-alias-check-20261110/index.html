A literature record is an extracted assay, not an independent paper. Several claims can share the same observation. Caching and different agent decisions confound this comparison; it is not a controlled ablation.

What changed in this revision

  1. Source-local repair. A newly refused extraction receives one bounded retry per source/location before another discovery round. The retry includes the exact failure, original read ID and whole-sentence selectors. Code copies the selected sentence verbatim, then applies the existing assay, scope, identity and direction checks. Accepted experiments and earlier failed attempts remain auditable.
  2. Three-state identity. Same variant, different variant and unresolved are separate outcomes. A bounded set of catalogue SNV names is checked against exact NCBI placements in the catalogue's declared build. The names and their identity status are visible to every investigator; only verified matches establish a case alias. A numeric suffix or a complementary name alone never establishes identity.
  3. Paper-scoped observations survive. A nucleotide shorthand actually named in a promoter/sequence experiment can be retained in that paper's namespace. Without a verified mapping, it cannot support or contradict a case-variant claim. Exact catalogue name, gene and ordered alleles can supply a mapping; original notation and strand conversion remain in provenance.
  4. No-change reading control. Repeated abstract text now participates in the same content-based check as full text. New source passages or genuinely different claim scopes remain investigable. The original call and currency caps still apply, including the audit and final-comparison reserve.

These are general rules. No variant-specific genes, factors, expected answers or primary-paper lists were added to production code. Both new runs received only coordinates, alleles and origin; prior runs and gold files remain unchanged.

Did the repair run in practice?

Refused extraction → original saved source → one repair attempt → normal verification → retained evidence or an explicit processing gap. No additional HTTP request is needed for this repair. A valid copied sentence still has to pass the scientific checks.

How to read the result

Finding a paper, retaining an experiment, mapping its variant and supporting a claim are separate checkpoints. An unresolved paper-scoped assay is useful progress, but it is not case-specific molecular recovery. A reporter result cannot establish an endogenous mechanism, and binding support cannot by itself complete a disease chain.

The case audits above identify the actual remaining gaps and refused updates. No run was repeated simply until a desired biological answer appeared. Before/after comparisons use known positive development cases and different agent decisions; they do not establish generalisation or isolate a causal effect for each change.

What still needs work

  1. Separate experimental comparisons within a passage. The rs12740374 paragraph describes both minor-versus-major binding and antibody-induced impairment. The original direction check conflated them; repair retained a direction-unspecified observation. A future comparison-scoped representation should identify the intervention, comparator and endpoint for each result before assigning polarity.
  2. Resolve paper-local allele labels explicitly. Minor/major labels still cannot be turned into T/G without an audited definition. Search existing figure captions, tables and sequence legends for that definition, retaining each location. An image-only definition needs an image-capable evidence route; otherwise leave it unresolved.
  3. Reuse claims and correct invalid links. Unassessed duplicate reporter drafts remain beside their supported successors. Group-level prediction links were refused because their rationale did not identify the model's members; the critic noticed this but the final graph did not repair the link. These are graph-update problems, not missing biology.
  4. Make alias searches more selective. The TERT run issued a loosely grouped OR query before finding the primary study. A query builder that quotes aliases and groups Boolean clauses could reduce irrelevant results. This was not changed after seeing the rerun.

These are remaining limitations and suggested next steps, not additional fixes claimed as complete. Neither adding more agents nor simply increasing the currency budget resolves them.
